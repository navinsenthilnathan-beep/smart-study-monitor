## 🌟 Why You'll Love It

Say goodbye to boring spreadsheets and scattered report cards! The **Student Monitoring System** turns academic tracking into something genuinely *fun* to look at — think colorful gradients, glowing stat cards, and live charts that make progress feel like a game you're winning. 🏆

Whether you're a **student** chasing your next milestone, a **parent** keeping an eye on multiple kids, or a **mentor** managing a whole classroom — this app has a dashboard tailor-made for you.

---

## 🧩 Core Features

### 🙋 Role-Based Login
Choose your role — **Student**, **Parent**, or **Mentor** — and instantly land on a dashboard built just for you.

### 📊 Student Dashboard
- ✅ Today's attendance status at a glance
- ⏱️ Live study time tracker (`6h 30m` and counting!)
- 📈 Attendance rate with weekly bar charts
- 🏅 Achievement counter to celebrate wins
- 📚 "Today's Subjects" breakdown with time spent per subject
- 🎯 Personal goals with progress bars (because finishing that math assignment *feels* good)

### 👨‍👩‍👧 Parent Dashboard
- 👀 Monitor **multiple children** side-by-side (attendance %, performance rating)
- 📅 Monthly attendance overview with interactive weekly bars
- 📌 Overall stats: average attendance, total study hours, assignments completed
- 🏆 Recent achievements feed — never miss a proud parent moment

### 🧑‍🏫 Mentor Dashboard
- 🔍 Powerful student search (by name, grade, or email)
- 🗂️ Full student roster with attendance and performance at a glance
- ⚡ Quick "Select Student" action to dive into individual profiles
- 📢 Manage and monitor progress across your entire class

### 💎 Premium Features (Coming Soon!)
Unlock advanced analytics for deeper insights into performance trends. 🔓

## 🚀 Getting Started

```bash
# 1. Clone the repo
git clone https://github.com/your-username/student-monitoring-system.git

# 2. Move into the project folder
cd student-monitoring-system

# 3. Install dependencies
npm install

# 4. Run the app
npm start
```

Then open `http://localhost:3000` and pick your role to jump in! 🎉
