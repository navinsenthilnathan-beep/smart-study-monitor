# 📚 Smart Study Monitor

Smart Study Monitor is an IoT-based student engagement monitoring system that helps teachers monitor study sessions without using cameras.

## Features

- Arduino Uno Integration
- IR Sensor Presence Detection
- Student Dashboard
- Teacher Dashboard
- Attendance Tracking
- Productivity Analytics
- Gamification
- Responsive Interface

## Tech Stack

Frontend
- HTML
- CSS
- JavaScript

Backend
- Node.js
- Express

Database (Planned)
- MongoDB

Hardware
- Arduino Uno
- IR Sensor
- LEDs
- Buzzer
